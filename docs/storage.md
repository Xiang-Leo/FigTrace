# 图片存储位置

在「设置与备份 → 图片存储位置」可为上传、AI 生成和 SVG 编辑的原图副本设置独立目录。数据库、预览缓存和上传临时文件继续保存在本机图库数据目录；通过「关联目录」添加的原文件保持原位。

1. 选择一个空目录，或输入完整绝对路径创建专用文件夹。
2. 点击「保存图片存储位置」。FigTrace 复制并校验现有原图，全部成功后切换到新位置。图片较多时需等待复制完成。
3. 以后上传和生成的图片写入新目录。旧目录的副本保留，后续不会与新目录同步；请确认新目录和自己的原图备份可用后再自行处理旧副本。

目标也可以是网盘客户端在本机提供的可访问目录。FigTrace 完成本机文件写入，不保证网盘已经同步完成；离线或占位文件需先恢复可用。原图目录不可与数据库、缓存、备份或关联素材目录重叠，以免混用文件。错误或空间不足时，当前存储位置保持不变，复制成功的文件可供重试复用。

「图库信息备份」仍只备份项目、标签、分类、版本和路径信息，不包含原图片。恢复元数据时保留当前图片目录；在另一台电脑恢复时，需要另外准备原图并设置对应的图片目录。网盘中的原图不会自动同步本机 SQLite 图库。

远程浏览器只显示存储路径，不能重定向服务器文件写入。目录选择指向运行 FigTrace 后端的电脑。
